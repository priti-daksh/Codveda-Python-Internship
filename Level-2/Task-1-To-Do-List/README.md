# 📝 To-Do List Application

A simple command-line To-Do List Application built using Python as part of my Python Development Internship at Codveda Technologies.

## 🚀 Features

- ➕ Add new tasks
- 👀 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks permanently using JSON
- ⚠️ Basic error handling for invalid input

## 🛠️ Technologies Used

- Python
- JSON

## 📁 Project Structure

Task-1-To-Do-List/
│
├── todo.py
├── tasks.json
└── README.md

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python todo.py
```

Add Task
View Tasks
