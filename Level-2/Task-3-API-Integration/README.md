# 🌤️ Weather Information App

A simple Python application that fetches real-time weather information using an external API.

This project was developed as part of my Python Development Internship at Codveda Technologies.

## 🚀 Features

- 🔍 Search weather by city name
- 📍 Display city and country
- 🌡️ Display current temperature
- 🤗 Display feels-like temperature
- 💨 Display wind speed
- ❌ Handle invalid city names
- ⚠️ Handle API connection errors

## 🛠️ Technologies Used

- Python
- Requests Library
- Open-Meteo API

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required library:

```bash
pip install requests
```

## Run the application:

    python weather_app.py
