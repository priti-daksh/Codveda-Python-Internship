# Simple Calculator

A simple calculator application built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by Zero Handling
- Invalid Input Handling

## Technologies Used

- Python

## How to Run

1. Open the project folder.
2. Open the terminal.
3. Run the following command:

```bash
python calculator.py
```
