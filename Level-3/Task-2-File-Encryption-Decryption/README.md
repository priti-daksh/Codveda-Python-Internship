# 🔐 File Encryption and Decryption

A Python application that allows users to encrypt and decrypt files using Fernet encryption.

This project was developed as part of my Python Development Internship at Codveda Technologies.

## 🚀 Features

- 🔐 Encrypt any text file
- 🔓 Decrypt encrypted files
- 🔑 Secure encryption using Fernet
- 📁 User can enter the file name
- ⚠️ Handles file not found errors
- ❌ Handles invalid decryption errors
- 🚪 Exit option

## 🛠️ Technologies Used

- Python
- Cryptography Library
- Fernet Encryption

## ▶️ How to Run

1. Open the project folder in VS Code.

2. Open the terminal.

3. Install the required library:

```bash
pip install cryptography
```

4. Run the application:

```bash
python file_encryptor.py
```

5. Select an option:

```text
1. Encrypt File
2. Decrypt File
3. Exit
```
