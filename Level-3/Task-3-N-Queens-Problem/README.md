# ♛ N-Queens Problem Solver

A Python program that solves the classic N-Queens problem using the Backtracking algorithm.

This project was developed as part of my Python Development Internship at Codveda Technologies.

## 🚀 Features

- ♛ User can enter the number of queens
- 🧩 Creates an N × N chessboard
- 🔄 Uses Backtracking algorithm
- ✅ Checks safe queen positions
- 📍 Prevents queens from sharing the same column
- ↖️ Checks left diagonal conflicts
- ↗️ Checks right diagonal conflicts
- ❌ Displays a message when no solution exists
- ⚠️ Handles invalid input

## 🛠️ Technologies Used

- Python
- Backtracking Algorithm
- 2D Array

## ▶️ How to Run

1. Open the project folder in VS Code.

2. Open the terminal.

3. Run the application:

```bash
python n_queens.py
```

4. Enter the number of queens.
